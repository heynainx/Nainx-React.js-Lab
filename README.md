# Nainx-React.js-Lab
NainX React JS Lab

A premium React JS learning platform from zero to pro for frontend developers

Live Demo
Find live demo on Vercel search nainx react js lab

About This Project
This lab contains more than five hundred React JS programs from basic to pro level
You can learn practice build projects and get certificate

Features

More than five hundred React JS programs with explanation and output
JSX components props state hooks useEffect useRef context redux routing forms custom hooks performance optimization real projects
Live code preview with instant render in browser
Quizzes with instant result and explanation
Strict exam mode with timer and tab switch warning
Certificate generator with QR code and verifier page
Transcript system to download full report as PDF
Full auth system with full name username email password and repassword
Full name is used for certificate
Dark and light mode with glassmorphism design
Command palette to search any program fast
Progress dashboard with XP badges streaks and weak topic analysis
PWA support to install as app

Tech Stack

Frontend React plus Vite plus JavaScript plus Tailwind CSS plus Framer Motion
Code Editor Monaco Editor same as VS Code
Backend and Database Supabase free Postgres and Auth
PDF Generator jsPDF with QR code

Setup Locally

First clone the repo
Second install dependencies with npm install
Third run dev server with npm run dev
Fourth add env file with Supabase url and anon key

Supabase Tables

Table profiles with id fullName username email xp level
Table certificates with id userId userName course score date
